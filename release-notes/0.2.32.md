**agent-farm now needs macOS 27 (Golden Gate) or later.** The copy of Python inside the app is built for macOS 27. On macOS 26 or earlier this update won't install: **Check for Updates…** says your macOS version is too old. You can still run agent-farm from source in a terminal; the README says how.

- **The version is in the title bar.** The header bar inside the window is gone (it repeated the title and showed a clock), so the window has one more row. The title reads 🌾 agent-farm and its version, then one 🐓 per busy or waiting session.
- **New setting: Report to agent-grange.** A list of patterns that choose which sessions to share with your team through agent-grange, each with its own on/off button, and a few example names each one matches. Nothing is sent yet; this release only keeps the list.
- If the monitor inside the window stops unexpectedly, the title no longer keeps showing 🐓 for sessions nothing is watching.
- Updated libraries.
